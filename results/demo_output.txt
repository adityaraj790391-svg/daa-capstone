3. SHORTEST PATHS AND DELIVERY ROUTE
   Dijkstra is run from each selected stop to build shortest-path distances.

   Total route distance: 26.00 km

4. ALGORITHM COMPLEXITIES
   Merge Sort          : O(n log n) time, O(n) extra space
   0/1 Knapsack DP     : O(nW) time and O(nW) space
   Dijkstra (heap)     : O((V + E) log V) time
   Nearest Neighbor TSP: O(k^2) time, O(k) extra space
