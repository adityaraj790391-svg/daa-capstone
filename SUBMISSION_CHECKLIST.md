
1. Open `report/Mini_Courier_Planner_Report.docx` and replace the placeholders for student name, roll number, semester/section, and submission date.
2. Export the edited DOCX to PDF again, or update `report/Mini_Courier_Planner_Report.pdf` using the final student details.
3. Open Terminal in this project folder and run `python main.py`.
4. Run `python run_tests.py` and confirm that all tests pass.
5. Keep `data/`, `courier_planner/`, `main.py`, `benchmark.py`, `requirements.txt`, `README.md`, `results/`, and `report/` together.
6. Upload the ZIP through Zosima or push the folder to an accessible GitHub repository, as allowed by the assignment instructions.

The supplied parcel, customer and road data is sample data for demonstration. Replace it with your own dataset only if your faculty expects a different scenario.
